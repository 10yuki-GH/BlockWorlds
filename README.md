# BlockWorlds Downloads

This folder contains the BlockWorlds GitHub Pages download site.

## Publishing

Upload everything in this folder to the root of a GitHub repository. In **Settings → Pages**, publish from the root of the main branch.

Keep this structure unchanged:

```text
index.html
assets/icon.png
downloads/BlockWorlds-Alpha-0.1.dmg
downloads/BlockWorlds-Alpha-0.2.dmg
downloads/BlockWorlds-Alpha-0.3.dmg
downloads/BlockWorlds-Alpha-0.4.dmg
```
