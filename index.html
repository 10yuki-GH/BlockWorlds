Installation guide

BLWS is the current name of the game. BlockWorlds is its former name, used by Alpha 0.1–0.4 and some older files.

macOS

  1. Download the version you want and drag its App to Applications.
  2. Open Terminal and run the command below before the first launch. Enter 0.1, 0.2, 0.3, 0.4, or 0.5 when asked.
read "VERSION?Enter BLWS/BlockWorlds version (0.1, 0.2, 0.3, 0.4, or 0.5): "
if [ "$VERSION" = "0.5" ]; then APP="BLWS Alpha 0.5.app"; else APP="Alpha $VERSION.app"; fi
mkdir -p "$HOME/Applications"
ditto --norsrc --noextattr --noqtn --noacl \
  "/Applications/$APP" \
  "$HOME/Applications/$APP"
codesign --force --deep --sign - "$HOME/Applications/$APP"
open "$HOME/Applications/$APP"

The command creates a clean personal copy, applies a local ad-hoc signature, and opens it. It is for BLWS downloaded from this official repository only.
